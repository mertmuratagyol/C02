42 C Piscine - C02

This repository contains my solutions for the C02 project of the 42 Kocaeli C Piscine.

About the Project

The C02 project focuses on string manipulation and array operations in C. It covers essential functions for handling strings, copying, concatenating, checking characters, and manipulating memory while strictly adhering to the Norm coding standards.

Exercises

* Ex00: Copies a string to another (ft_strcpy.c)
* Ex01: Copies up to n bytes from a string (ft_strncpy.c)
* Ex02: Checks if a string contains only alphabetical characters (ft_str_is_alpha.c)
* Ex03: Checks if a string contains only digits (ft_str_is_numeric.c)
* Ex04: Checks if a string contains only lowercase characters (ft_str_is_lowercase.c)
* Ex05: Checks if a string contains only uppercase characters (ft_str_is_uppercase.c)
* Ex06: Checks if a string contains only printable characters (ft_str_is_printable.c)
* Ex07: Converts a string to uppercase (ft_strupcase.c)
* Ex08: Converts a string to lowercase (ft_strlowcase.c)
* Ex09: Capitalizes the first letter of each word (ft_strcapitalize.c)
* Ex10: Copies a string with a size constraint and returns total length (ft_strlcpy.c)
* Ex11: Displays a string in a non-printable hexadecimal format (ft_putstr_non_printable.c)
* Ex12: Prints the memory address and content of a memory area (ft_print_memory.c)

Technologies & Rules

* Language: C
* Compiler: gcc (with -Wall -Wextra -Werror flags)
* Standard: 42 Norm (Norminette compliant)
